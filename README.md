# Concrete & Reinforcement Quantity Calculator

A web-based tool for civil engineers to quickly estimate concrete and steel reinforcement quantities for construction projects. Built to speed up quantity surveying workflows that are typically done manually or in Excel.

**🔗 Live Demo:** [Try it here](https://construction-quantity-calculator--majidalqobidhah.replit.app/calculator/)

## Features

- Concrete volume and steel reinforcement quantity calculations
- Full Arabic language support (RTL layout)
- Export results as PDF reports
- Responsive, modern interface

## Tech Stack

**Frontend:** React, TypeScript, Vite, Tailwind CSS, Radix UI
**Backend:** Express.js, PostgreSQL (Drizzle ORM)
**Other:** jsPDF (report export)

## About This Project

Developed as a practical tool to reduce time spent on manual quantity takeoffs in residential and infrastructure projects, drawing on hands-on experience in quantity surveying for building and road projects in Yemen.
